# Danish Spit vs Mosquitoes

A browser-playable version of the arcade game. It uses HTML Canvas and needs no build step or external libraries.

## Play locally

From this folder, run `python3 -m http.server 8000` and open `http://localhost:8000` in a browser. The game supports mouse, keyboard, and touch controls.

## Share it online

Publish this folder as a static website using a host such as GitHub Pages or Netlify. Include `index.html`, `game.js`, both `danish_*.png` artwork files, and both MP3 files. Once the host gives you a public URL, open it and use **Share game** to send the link to others.

The artwork files are named `.png` but contain JPEG image data; the game handles this when loading them.# GAME
